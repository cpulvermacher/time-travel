在 JavaScript Date、Intl.DateTimeFormat 或 Temporal 对象中模拟当前的日期、时间和时区。
Time Travel 可帮助您调试与时间相关的前端应用，而无需更改系统时间。

功能：
- 模拟 `Date` 和 `Intl.DateTimeFormat` 对象所有方法的日期和时间；如果浏览器支持，也会模拟 `Temporal.Now`。
- 可更改时区，并完整支持夏令时的切换。
- 可停止和恢复时钟。
- 可选择在更改日期后自动重新加载页面。
- 点击扩展程序图标后，只会影响当前标签页。

限制：
- 扩展程序只影响 JavaScript。
- 时钟停止时，部分功能或动画可能会出现异常。
- 扩展程序无法在带有 `sandbox` 属性的 iframe 中运行。

使用方法：
- 打开要更改时间的标签页。
- 点击工具栏中的“扩展程序”图标，然后点击 Time Travel。
- 从日历中选择日期并根据需要编辑时间，或直接输入日期和时间（请参阅下方示例）。
- 按 `Enter` 或点击应用按钮确认。按钮会预览将要应用的更改（例如“将日期更改为 2025年4月27日 12:40”）。
- 当前标签页中的所有 JavaScript `Date`、`Intl.DateTimeFormat` 或 `Temporal.Now` 都会返回您设置的模拟日期和时间。其他标签页和来源不受影响。

要恢复系统时间，请点击扩展程序图标并关闭“模拟 JavaScript 日期”开关，或清空输入框后按 `Enter`。

启用模拟日期后，时钟会从设置的时间开始继续走动。当前页面时间显示在“页面时间：”下方；扩展程序关闭时，这里显示实际时间。
打开“停止时钟”开关即可停止时钟，模拟日期会重置为您最后设置的值。

要更改时区，请启用“更改时区”，然后从下拉菜单中选择时区。
启用后，`Date` 对象、`Intl.DateTimeFormat` 和 `Temporal.Now` 将使用此时区，而不是系统时区。
输入的日期和时间也会被解释为所选时区的本地时间（输入框标签会显示例如“设置日期和时间（伦敦）”）。
切换到其他时区时，会保留输入的*本地*日期和时间，因此实际的时间点可能会改变（除非输入框中是 UTC 时间）。

实际页面时间旁的徽章会显示当前使用的 UTC 偏移，并用图标标明该日期处于夏令时还是标准时间。
将鼠标悬停在徽章上即可查看更多详细信息。

日期与格式示例：
- `2025-04-27 12:40` - 本地时间
- `2025-03-30 00:59:55` - 假设系统时区为 Europe/London (GMT)，即时间向前跳一小时到凌晨 2 点（夏令时）前 5 秒
- `2025-04-27T12:40Z` - 设置为指定 UTC 时间对应的本地时间
- `2025-04-27T12:40+1130` - 设置为 +11:30 时区偏移时间对应的本地时间。请注意，实际时区不会更改
- `2025-03-25T12:40:00.120` - 带毫秒的本地时间
- `1731493140025` - UNIX 时间戳
