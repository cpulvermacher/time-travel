在 JavaScript Date、Intl.DateTimeFormat 或 Temporal 物件中模擬目前的日期、時間和時區。
Time Travel 可協助您除錯與時間相關的前端應用程式，而不必變更系統時間。

功能：
- 模擬 `Date` 與 `Intl.DateTimeFormat` 物件所有方法的日期和時間；若瀏覽器支援，也會模擬 `Temporal.Now`。
- 可變更時區，並完整支援夏令時間的轉換。
- 可停止及恢復時鐘。
- 可選擇在變更日期後自動重新載入頁面。
- 點擊擴充功能圖示後，只會影響目前的分頁。

限制：
- 擴充功能只會影響 JavaScript。
- 時鐘停止時，部分功能或動畫可能會出現異常行為。
- 擴充功能無法在具有 `sandbox` 屬性的 iframe 中運作。

使用方式：
- 開啟要變更時間的分頁。
- 點擊工具列中的「擴充功能」圖示，然後點擊 Time Travel。
- 從日曆中選擇日期並視需要編輯時間，或直接輸入日期和時間（請參閱下方範例）。
- 按下 `Enter` 或點擊套用按鈕確認。按鈕會預覽將套用的變更（例如「將日期變更為 2025年4月27日 12:40」）。
- 目前分頁中的所有 JavaScript `Date`、`Intl.DateTimeFormat` 或 `Temporal.Now` 都會傳回您設定的模擬日期和時間。其他分頁及來源不受影響。

若要恢復系統時間，請點擊擴充功能圖示並關閉「模擬 JavaScript 日期」開關，或清空輸入欄位後按下 `Enter`。

啟用模擬日期後，時鐘會從設定的時間開始繼續走動。目前的頁面時間會顯示在「頁面時間：」下方；擴充功能關閉時，這裡會顯示實際時間。
開啟「停止時鐘」開關即可停止時鐘，模擬日期會重設為您最後設定的值。

若要變更時區，請啟用「變更時區」，然後從下拉式選單中選擇時區。
啟用後，`Date` 物件、`Intl.DateTimeFormat` 與 `Temporal.Now` 會使用此時區，而非系統時區。
輸入的日期和時間也會被解讀為所選時區的當地時間（輸入欄位標籤會顯示例如「設定日期和時間（倫敦）」）。
切換到其他時區時，會保留輸入的*當地*日期和時間，因此實際的時間點可能會改變（除非輸入欄位中是 UTC 時間）。

實際頁面時間旁的徽章會顯示目前使用的 UTC 偏移，並以圖示標示該日期屬於夏令時間或標準時間。
將滑鼠游標移到徽章上即可查看更多詳細資訊。

日期與格式範例：
- `2025-04-27 12:40` - 當地時間
- `2025-03-30 00:59:55` - 假設系統時區為 Europe/London (GMT)，即時間向前跳一小時到凌晨 2 點（夏令時間）前 5 秒
- `2025-04-27T12:40Z` - 設定為指定 UTC 時間對應的當地時間
- `2025-04-27T12:40+1130` - 設定為 +11:30 時區偏移時間對應的當地時間。請注意，實際時區不會變更
- `2025-03-25T12:40:00.120` - 含毫秒的當地時間
- `1731493140025` - UNIX 時間戳記
